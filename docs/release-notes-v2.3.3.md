# SyncWatch同步观影 v2.3.3 发布说明

# v2.3.3 更新公告

## 本轮修复

- 修复 Android 手机网页房间底部播放进度、清晰度和控制按钮在窄屏下被裁切、重叠或遮挡的问题。
- 修复聊天展开、表情栏、反应栏和播放器工具区来回切换时的布局冲突；移动端表情列表限制高度并独立滚动，聊天区域按内容自然增高。
- 取消手机进入全屏时自动横屏；仍保留用户主动选择竖屏、横屏或自动横屏的按钮。
- 保留内网穿透共享画面的 ACK 延迟自适应、最新帧队列和单帧大小保护。

## 验收与发布边界

- 已通过完整 `npm run test:all`、移动端 Chromium/Electron UI 冒烟、Android 390×844/844×390 布局检查、全屏层级与聊天滚动回归。
- Windows、Android 和 Windows 上的 Node.js/cloudflared 官方工具按发布清单构建与核验；正式 Release 必须有 8 个维护者资产和 2 个 GitHub 源码归档。
- 所有 SyncWatch 应用资产均须由最终 v2.3.3 Tag 对应源码真实重建，完成版本、平台、启动、闭包、大小和 SHA-256 核验后才能上传。
