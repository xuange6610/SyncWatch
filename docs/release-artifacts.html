校验与安装

  1. 只从 GitHub Releases 下载与平台匹配的文件。
  2. Windows 用 Get-FileHash .\\SyncWatch-v2.3.1-Full-Offline-Portable-x64.exe -Algorithm SHA256 核对哈希。
  3. 完整便携版放到有写入权限的普通文件夹后双击。
  4. 首次登录立即修改默认管理员密码。
  5. 独立服务器 ZIP 需要 Node.js 22+；正式 Windows EXE 不要求用户安装 Node.js。

Cloudflared 与 Node.js

cloudflared 是 Cloudflare Tunnel 连接器，用于把本机 HTTP、Socket.IO 和媒体 Range 请求转发为 HTTPS 公网地址。完整服务器包已优先使用内置文件，手工安装时只从 Cloudflare 官网 或 官方 Release 下载 并校验 SHA-256。Node.js 安装包只给源码开发和独立服务器使用；它不是 Windows EXE 的运行前置，可从 Node.js 官网 或 官方下载 获取。

v2.3.1 的 Windows 体验版、Windows 完整便携版和 Android APK 已从最终 Tag 重新构建；2 项 Windows Node.js 与 3 项 Windows cloudflared 文件也已按官方来源核验。Release API 当前恰有 8 个维护者资产。
