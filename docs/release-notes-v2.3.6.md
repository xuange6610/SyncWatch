# SyncWatch同步观影 v2.3.6 发布说明

## 更新公告

- 修复 Windows 完整离线便携版使用已有旧数据目录时的启动兼容问题：迁移旧目录会保留账号、房间、媒体、聊天和设置，并跳过旧运行锁，避免把历史实例锁误判为当前实例。
- 对历史配置中表示“自动选择端口”的 `0` 做兼容迁移，统一使用默认端口 `20311`；固定端口被占用时显示具体端口和处理建议，不再随机切换。
- 修复顶部“在线成员”双击编辑人数上限时的事件冒泡，不会再同时打开“界面风格”设置窗口；人数编辑仍按房间管理权限执行。
- 同步更新 Windows、Android、Web、README、部署教程、Pages/Wiki 源文档和发布契约中的版本号与启动说明。

## 发布资产与验收边界

- 正式 Release 必须包含 8 个维护者资产和 GitHub 自动生成的 2 个源码归档；Windows/Android 应用包必须由最终 `v2.3.6` Tag 对应源码真实重建。
- 发布前仍需完成 Windows/Android 启动与核心流程、旧数据目录回归、包内源码闭包、版本、平台/架构、非空大小和 SHA-256 核验，并回读 GitHub Release、README、Pages 与 Wiki。
