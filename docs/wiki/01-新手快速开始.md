# 新手快速开始

## 1. 选择下载文件

房主下载 Windows 服务器 EXE；成员下载对应平台客户端或直接用浏览器；Mac 按 Intel x64 / Apple Silicon arm64 选择；Android 安装 APK。不要把 Release 页的 `Source code (zip)` 当作安装包。

## 2. 双击启动

1. 把服务器 EXE 放在有写入权限的普通文件夹。
2. 双击启动。正式 EXE 已内置 Electron、Node.js 运行时、FFmpeg/FFprobe 和 Windows cloudflared，不需要预装 Git、Node.js 或 npm。
3. 程序会初始化 `SyncWatch同步观影-Data/`，检测端口并打开桌面窗口。端口被占用时，以软件显示的新地址为准。
4. 连续双击不会启动第二个实例，第二次启动会聚焦已运行窗口。

## 3. 首次登录和建房

1. 使用 `admin` / `admin888` 登录。首次账号密码认证成功后，改密向导只要求填写新密码和确认密码，不会再次要求输入当前密码；可暂不更改，但公网部署前必须完成。
2. 进入“账户与注册”或“服务器设置”确认管理员密码策略，并撤销不需要的旧会话。本机免密管理入口和普通账号周期改密仍可能要求当前密码。
3. 进入“房间与上传”，点击“新建房间”，填写名称、人数上限和房间密码。
4. 选择合法影片或安全文本，等待上传、FFprobe 分析和缩略图生成完成。文本阅读单文件上限为 10 MB。
5. 点击“批准上传”，把媒体设为房间可见；点击“加入队列”后由房主开始播放。选择文本后，房主/控制权成员可用滚动或页码同步阅读，成员会跟随服务器广播的位置。

## 4. 让成员加入

同一 Wi-Fi 下先使用软件显示的局域网地址测试。成员可以用浏览器或客户端输入地址，登录后输入房间密码。确认播放、暂停、拖动进度、倍速和文本阅读字符锚点都同步后，再配置公网访问。文本阅读验收至少用房主和一个普通成员两个独立会话测试滚动、页码、重连、窗口尺寸调整和切换文件。

## 5. 结束与备份

停止公网 Tunnel，退出服务器，使用“服务器设置 → 数据导入与导出”导出全部数据，或复制整个 `SyncWatch同步观影-Data/`。恢复前先停止服务，恢复后检查房间、媒体、聊天、`secrets` 和缩略图，再启动。
