# v2.4.4 更新公告

SyncWatch同步观影 v2.4.4 针对公网入口“能打开但视频一直缓冲”的剩余问题补充修复。本页描述已公开正式版的播放兼容修复与验收结果。

## 本次修复

- 服务端播放快照按已知媒体时长封顶；播放到末尾自动暂停并广播最终位置，避免房间长期打开后新成员跳到越界时间。
- 客户端原画偏好遇到 MKV、HEVC、10-bit 或浏览器不支持的容器/编码时，如果 H.264/AAC 兼容版已生成，自动切换到兼容源；可直接播放的 MP4/H.264 仍使用原片。
- 增加播放时钟、兼容源选择和缺少媒体时长回退的回归测试，保留 Range、MIME、NAT/反向代理和网络恢复检查。

## 发布边界

v2.4.4 的 Windows 体验版、Windows 完整便携版和 Android APK 已由最终 Tag 对应源码真实重建，并完成启动、哈希、隐私和远端回读；Node.js/cloudflared 使用已核验的官方缓存。Release API 已有 8 个维护者资产，页面另含 2 个源码归档并设为 Latest，历史 Release、Tag 和资产保持不变。
