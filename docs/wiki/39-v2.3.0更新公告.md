v2.3.0 已公开为 Latest，并正在执行同版本纠正覆盖。新的 Windows/Android 应用资产必须重新构建并通过启动、SHA-256 和 GitHub Release 回读；Release API 仍保持 8 个维护者资产，页面另含 2 个 GitHub 源码归档，共 10 个可见文件。

## 从 v2.2.9 到 v2.3.0

- 统一版本、Android 元数据、下载文件名和构建配置为 v2.3.0 / `20300`。
- 保留 Windows、Android 和浏览器支持，不再构建或上传新的 macOS 包。
- 保留全屏 `L` 锁定、`F2`/回车边看边聊、顶栏分组与折叠、主题状态、房间搜索、权限申请、网页共享与继续播放等既有能力。
- 发布流程修复 Android APK 版本校验、模拟器 ADB 瞬态 Broken pipe 重试和 Windows Electron EPIPE 烟测生命周期，并用自动化契约锁定。
- 同版本纠正更新增加 WebRTC 音视频优先传输、有界 JPEG/PCM 兜底、48 kHz Int16 低延迟音频、原生分辨率与设备最高刷新率默认请求，以及系统实际授予值展示。
- 房间实时显示音频共享者、媒体标题、进程名和来源；同一会话瞬断后迁移到新连接，停止、断线超时或切房后立即清空。手机/网页自动播放受限时提供“开启声音”，状态条不会遮挡播放进度拖动。
- WebRTC 画面瞬断会立即恢复有界 JPEG 兜底并自动重建；共享信令按共享者/观看者方向校验和限流，阻止反向媒体注入。
- 主题同步申请会向申请者回传接受、拒绝或“已经是该风格”的右下角通知；相同风格的目标不会收到邀请打扰。
- Electron 启动立即显示等待窗口，本机页面真实加载完成后再关闭；短暂失败自动有界重试，最终错误有明确提示。
- 8 个维护者资产全部来自最终 Tag 构建或已核验官方分发，没有使用旧包改名、占位文件或残缺集合。

## 下载选择

- Windows 普通成员：`SyncWatch-Experience-Client-Portable-v2.3.0-x64.exe`。
- Windows 房主：`SyncWatch-v2.3.0-Full-Offline-Portable-x64.exe`。
- Android：`SyncWatch-Android-v2.3.0-universal.apk`。
- Node.js 与 cloudflared 文件是源码部署或公网连接工具，不是 SyncWatch 启动程序。

第一次使用服务器请以 `admin` / `admin888` 登录并立即修改默认管理员密码。升级前停止服务并备份整个 `SyncWatch同步观影-Data/`。

## 纠正覆盖边界

新 8 项资产完整构建和远端回读成功前，线上旧资产保持可下载；安全切换成功后只删除被替换的 v2.3.0 旧资产。历史 Release、历史 Tag 和历史资产全部保留。操作系统、浏览器、编码器和设备可能降低实际采集帧率或拒绝系统音频，因此不承诺固定 240 FPS 或物理零延迟。
