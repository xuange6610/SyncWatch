# v2.2.1 更新公告（候选）

v2.2.1 是基于 v2.2.0 的修复候选，当前尚未创建 Tag 或 Release，也没有可下载的 v2.2.1 成品。最新正式版本仍是 [v2.2.0](https://github.com/xuange6610/SyncWatch/releases/tag/v2.2.0)。

## 本轮真实变化

- **同步看小说**：房间状态新增精确 UTF-16 `characterOffset` 字符锚点，并保留 `fileId`、`position`、页码与递增 `revision`。所有成员、晚加入客户端和断线重连客户端恢复同一逻辑偏移与同一锚点字符；本地 Range 只负责把该字符所在视觉行滚到顶部，桌面和手机各自的换行行首不得回写覆盖权威锚点。专项浏览器回归包含非行首锚点 `1234` 与精确页边界 `1200`。
- **播放期间网络状态**：顶栏只根据 Socket.IO 控制通道探测显示“同步正常 / 网络波动 / 连接中断”，视频 `waiting/stalled`、单次 RTT 尖峰或其他成员短暂重连不直接触发“网络波动”。客户端前台每 4 秒最多保留一个在途探测；连续 3 次超过 500 毫秒或超时才降级，连续 2 次健康样本后恢复。后台页面不发起探测，后台返回的旧 ACK 被丢弃，回到前台后重新建立基线；递增 sequence、连接 epoch 和 volatile 遥测继续隔离乱序响应、旧连接迟到结果与重连期间积压消息。本机 socket 真正断开仍立即显示“连接中断”。
- **原画长播恢复**：超过 32 MiB 的媒体把开放 Range 从 1 MiB 调整为 8 MiB 有界分段，减少高 RTT 公网链路的周期性续段，同时继续在拖动中止时关闭旧文件流。媒体无进展时最多执行 5 次渐进退避，离线等待不消耗次数，重连后继续；原画仍失败且已有流畅版时再自动降级。
- **首次管理员改密**：内置 `admin` 只有在本次会话刚通过账号密码认证且服务器仍处于首次初始化时，才获得一次性免重复当前密码能力；向导只填写新密码和确认密码，新密码仍需至少 8 位且不能复用 `admin888`。成功后能力立即撤销，本机免密管理会话和普通周期改密仍需当前密码。
- **账号密码策略**：新账号和普通密码默认允许空格、标点、符号及 Unicode，不启用业务字符数限制；服务端保留用户名 1024 UTF-8 字节、密码 4096 UTF-8 字节的防滥用上限，管理员仍可显式启用更窄规则。
- **默认原画**：局域网、反向代理和 Tunnel 的新客户端默认使用原画，不再按连接方式自动降为流畅版；网络受限时可手动切换流畅版。
- **成员头像交互**：单击头像继续打开成员资料；桌面双击或触摸端 420 毫秒内快速点击两次打开大图，并取消待执行的单击。普通单击在 440 毫秒消歧后按账号重新定位当前头像控件，因此成员状态刷新重绘列表时不会丢失资料入口；预览支持关闭按钮、遮罩、Escape 和焦点返回。
- **桌面关闭弹窗**：鼠标悬停或键盘聚焦哪个操作，哪个操作使用与“最小化到托盘”一致的高亮，不再固定只高亮一个按钮。
- **统一界面文案**：超级管理员可在服务器设置中编辑显式稳定 key 和固定控件自动生成的 `ui.auto.*` key，也可双击界面条目修改，并导入、导出或恢复默认；保存后通过服务端实时同步在线客户端。自动目录排除影片名、账号、IP、Toast 和动态对话正文等运行数据；服务端最多接受 5000 项、每项 240 个字符和 2 MB 导入 JSON，只接受受控 key 与纯文本，拒绝 HTML、脚本、可执行协议、选择器及 DOM 路径。

## Wiki 与发布要求

- 每个版本完成真实变化后，要同时更新仓库 `docs/wiki/`、GitHub Wiki、主要 Markdown 教程与 Pages HTML；公告必须区分已实现源码、已验证成品和已发布线上状态。
- v2.2.0 的 Tag、Release、资产、哈希与发布历史保持不变；以上能力属于 v2.2.1，不能倒填成 v2.2.0 已发布功能。
- v2.2.1 的 17 个 SyncWatch 应用包必须全部从最终 Tag 对应源码重新构建并验证版本、平台/架构、非空大小、SHA-256、包内闭包和实际启动；不能复用、改名或复制 v2.2.0 包。
- Node.js 4 项和 cloudflared 5 项是上游官方分发文件，需另行核对官方来源、版本、平台/架构与 SHA-256，不能描述成 SyncWatch 启动程序。
- 只有 26 个维护者资产与两个最终 Tag 源码归档全部就绪、根目录 `dist/` 恰好 28 个非空文件且发布门禁通过后，才能一次性上传并把 v2.2.1 设为 Latest。

## 验证边界

源码已有小说精确字符锚点、网络状态迟滞与旧连接隔离、首次管理员一次性改密能力、账号密码策略、统一文案隐私边界、头像单击/双击及重绘竞态、默认原画和关闭弹窗的专项自动化覆盖；是否全部通过以本次候选最终门禁日志为准。浏览器视口与虚拟时间回归不等同于物理多设备、真实长时间播放或真实弱网验证。Windows、Android、macOS 成品、26+2 文件集合、v2.2.1 Tag、GitHub Release、Latest 标记和下载直链仍待验证；当前没有小米 14 / HyperOS 真机证据。
