# v2.3.9 更新公告

v2.3.9 已从最终 Tag 完成 Windows/Android 真实构建、启动验收、SHA-256 核对和 GitHub Release 远端回读，当前为公开 Latest。

## 移动端与上传修复

- 手机浏览器与 Android 运行时移除实时语音栏、悬浮播放和重复播放控件。
- 全屏与全屏自动锁屏固定在第一行，-10/+10 同行，画质/倍速同行，共享屏幕/共享电脑音源同行。
- 旧配置中的五分钟视频时长默认值自动迁移为不限；管理员仍可在房间设置中显式配置限制，0 表示不限。

## 发布资产

Release API 包含 8 个维护者资产，页面另有 GitHub 自动生成的 2 个源码归档，共 10 个可见文件。应用包均从 v2.3.9 Tag 源码重新构建并完成启动与哈希验收，历史版本资产保持不变。
