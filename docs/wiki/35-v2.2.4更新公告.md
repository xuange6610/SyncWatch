# v2.2.4 更新公告

v2.2.4 基于 v2.2.3，集中完善全屏观影、账户级简洁模式、地址隐私、房间复制/迁移、更新检查、播放权限和批量队列。该版本已正式发布并设为 Latest：[GitHub Release v2.2.4](https://github.com/xuange6610/SyncWatch/releases/tag/v2.2.4) 的 API 有 26 个维护者资产，连同两个源码归档页面共 28 个文件。

## 本轮改动

- 全屏弹幕保持可见；双击只调出边看边聊，不触发播放/暂停；全屏禁止普通通知和弹窗，`F12` 可切换全屏。
- 修复退出全屏后按钮丢失，以及浏览器缩放、低分辨率和低高度时聊天/退出入口不可达的问题。
- 新增账户级简洁模式，仅保留基础观影功能和进出房、进度拖动通知；新增“仅显示聊天内容”。
- 弹幕颜色与字号可由每个账号单独设置并同步。
- 普通客户端不再显示或分享局域网 IP；Tunnel/公网访问只展示一个可信公网地址，未知时不回退内网地址。
- 被授予超级管理员的普通账号不再强制改密；默认密码首次修改仍只针对内置 `admin`。
- 房主可申请复制另一房间的配置、队列、权限和媒体；来源房主同意后建立副本。内置超级管理员可二次确认后覆盖迁移到指定目标房间。
- 检查更新绕过缓存并兼容稳定 Release 版本字段；网络失败时明确显示缓存/失败状态，不误报“已是最新”。
- 快进/拖动权限从播放控制权限中独立出来；有控制权限的成员调整倍速后同步全房间。
- 管理员或房主可向指定用户发起清晰度切换申请，用户确认后只修改自己的播放源。
- 房间新增自动跳过片头/片尾秒数设置；片库和队列支持批量选择、批量加入与批量删除。
- 登录限流窗口新增申请清除入口，管理员可实时处理，未处理项保留在用户申请中心。
- 设备定位等敏感系统状态只给内置 `admin` 的受信管理会话，普通用户和后来被授予的超级管理员都不会收到。
- 注册限制申请支持填写账号数量并按数量部分/全部撤回；内置 `admin` 可在用户申请中心单条或批量删除记录。
- 账户管理只显示密码是否已安全设置、待修改/过期和更新时间；管理员无法查看明文或哈希，安全重置会撤销旧会话。
- “同步网址”由服务器保存 URL/revision 并在晚加入/重连时恢复，但各端 sandbox 独立加载，跨域、Cookie、地区和禁止嵌入仍可能造成差异；同一画面使用实时标签页/窗口共享。
- Web“关于”和 Electron“帮助”统一提供 GitHub 项目主页、Wiki、作者和许可证入口。
- 纯 Node 控制台不提供 Electron 菜单；`--help`、`--open-browser`、启动摘要和 `服务器运行信息.txt` 提供等价私密管理入口。

## 跨端与验证边界

- Windows、Android、macOS 和浏览器共用服务端房间、账户偏好和权限状态；服务器窗口与客户端窗口使用明确运行角色，避免地址泄露。
- Android 目标版本为 `versionName=2.2.4`、`versionCode=20204`；浏览器移动视口和 Android 模拟器结果不能替代小米 14 / HyperOS 真机验证。
- v2.2.4 的 17 个 SyncWatch 应用资产已由最终 Tag 对应源码重建；9 个 Node.js/cloudflared 资产已核对官方来源、平台、架构、大小和 SHA-256。
- 根目录 `dist/` 的原子发布审计必须恰好包含 28 个非空文件；GitHub 只上传 26 个维护者资产，两个源码归档由 GitHub 自动生成。

## 升级提示

升级前停止服务器并完整备份 `SyncWatch同步观影-Data/`。房间复制/迁移会实际复制媒体文件，请确认磁盘空间；管理员覆盖迁移前应额外保存目标房间备份。首次部署继续使用 `admin` / `admin888` 登录并立即改密。

完整下载选择、平台架构、26+2 资产门禁和已知限制见 [v2.2.4 发布说明](https://github.com/xuange6610/SyncWatch/blob/main/docs/release-notes-v2.2.4.md)。
