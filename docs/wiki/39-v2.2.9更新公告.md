# v2.2.9 更新公告

v2.2.9 已完成最终 Windows/Android 构建、启动、SHA-256 和 GitHub Release 资产核验，并已公开为 Latest。Release API 核对到 8 个维护者资产，页面另含 2 个 GitHub 源码归档，共 10 个可见文件。

最终注释 Tag 指向提交 `ba18ae482ae3604a2bca92246eeb365b8236735f`；原子发布运行 `33323728228` 已完成源码门禁、Android 模拟器、Windows 应用启动、完整离线闭包、Microsoft Defender 扫描、远端哈希回读和 Latest 发布。

## 本次更新

- 房间详情和公网访问按钮统一改为“分享房间号 / 分享内网地址 / 分享公网地址 / 分享地址”。浏览器、Windows 客户端与 Android WebView 使用同一份前端资源。
- 全屏按 `L` 可锁定或解锁画面操作；按 `F2` 或回车会打开“边看边聊”并聚焦输入框，正在输入时不会误触快捷键。
- 顶栏将常用功能收进“选项 / 房间操作 / 设置”；桌面端悬停临时展开、点击固定并在移出后自动收起，手机端使用显示完整名称的单列手风琴列表。
- 左右侧栏都提供醒目的折叠入口，右侧“在线成员”整个面板的按钮移入可见标题区并保持高亮；登录账号的折叠偏好由服务器保存并在下次进入时恢复。
- 登录页用户名、账号密码和房间号增加闪烁高亮框；房间密码旁实时显示“检测中 / 有密码 / 无密码”，必填但留空时提示“请输入房间密码”，只有输入错误时才提示“房间密码错误”。
- 网页和手机登录页恢复文档滚动；桌面顶栏状态、高 DPI 和超长文字布局增加兼容，避免只剩颜色条或名称丢失。
- 更换房间新增搜索框，可按房主名字、房主账号、房间号或房间名字实时模糊筛选自有房间；筛选计数、无结果提示和批量选择会跟随当前结果更新。
- 顶栏操作区在桌面窄窗口降低字号和间距，局域网地址在自身区域省略，避免“选项 / 房间操作 / 设置”与账户区挤压。
- 在线房间下拉菜单加宽并显示房间名、房主、房间号、在线人数及“密码：有/无”，登录页会定时刷新这些状态。
- “同步观影网址”改为打开目标网页后选择浏览器标签页或窗口实时共享，房间成员看到同一画面；兼容 iframe 预览明确标注为本机独立模式。
- 房间号改为必填并显示红色星号；房主退出与最小化到托盘的推荐按钮增加呼吸高亮；拖动进度提示仅保留最新一条。
- 局域网服务详情支持复制与打开地址，数据目录支持复制与打开；剪贴板失败时使用 Electron 原生回退。
- F11 提示窗口改为完整快捷键功能列表；下载与产品介绍文案按普通用户能理解的角色和用途重新整理。
- Electron 首先显示与银幕主题一致的启动页，再加载服务端模块；“运行信息”不再使用 Windows 默认白色对话框。
- v2.2.9 新构建只面向 Windows、Android 和浏览器，不再构建或上传新的 macOS 包；历史 Release 保持不变。

## 下载边界

当前正式 Release 为 8 个维护者资产，加 GitHub 自动生成的 2 个源码归档。应用包均由最终 Tag 对应源码真实构建并通过启动、版本、平台/架构、非空大小和 SHA-256 核验，没有使用旧包改名或占位文件。

真实 Chromium 烟测已覆盖桌面/移动顶栏、折叠、登录密码状态、全屏 `L`、`F2`、回车和聊天焦点。Actions 已验证 Windows 两个 EXE 启动、Android APK 签名与模拟器安装启动、Full Offline 闭包、Microsoft Defender 扫描和最终 10 文件集合。当前 Windows EXE 没有受信任的商业代码签名证书，因此不能承诺所有第三方杀毒软件永不误报；小米 14/HyperOS 真机也未在本轮验证。
