# v2.2.9 更新公告

v2.2.9 已完成最终 Windows/Android 构建、启动、SHA-256 和 GitHub Release 资产核验，并已公开为 Latest。Release API 核对到 8 个维护者资产，页面另含 2 个 GitHub 源码归档，共 10 个可见文件。

最终注释 Tag 指向提交 `fa577838c4ec50d28e61e66765c9ab4260ad8322`；原子发布运行 `33294235283` 已完成源码门禁、Android 模拟器、Windows 应用启动、完整离线闭包、远端哈希回读和 Latest 发布。

## 本次更新

- 房间详情和公网访问按钮统一改为“分享房间号 / 分享内网地址 / 分享公网地址 / 分享地址”。浏览器、Windows 客户端与 Android WebView 使用同一份前端资源。
- 全屏按 `L` 可锁定或解锁画面操作；按 `F2` 或回车会打开“边看边聊”并聚焦输入框，正在输入时不会误触快捷键。
- 顶栏将常用功能收进“选项 / 房间操作 / 设置”，并修复关闭菜单后内部按钮仍在屏幕外占位的问题。
- 左右侧栏都提供醒目的折叠入口，登录账号的折叠偏好由服务器保存并在下次进入时恢复。
- Electron 首先显示与银幕主题一致的启动页，再加载服务端模块；“运行信息”不再使用 Windows 默认白色对话框。
- v2.2.9 新构建只面向 Windows、Android 和浏览器，不再构建或上传新的 macOS 包；历史 Release 保持不变。

## 下载边界

当前计划为 8 个维护者资产，加 GitHub 自动生成的 2 个源码归档。应用包必须由最终 Tag 对应源码真实构建并通过启动、版本、平台/架构、非空大小和 SHA-256 核验，不能使用旧包改名或占位文件。

源码检查和真实 Chromium 烟测已经覆盖移动顶栏、全屏 `L`、`F2`、回车和聊天焦点。Windows EXE、Android APK、签名、杀毒软件结果与最终 Release 文件数仍以最终构建和远端核验为准。
