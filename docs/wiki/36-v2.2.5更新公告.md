# v2.2.5 更新公告

v2.2.5 基于 v2.2.4，重点完善影片管理、账号身份迁移、退出即时生效、协议拒绝后的登录恢复和邮件模板即时预览。

## 本版变化

- 我的影片新增批量重命名，支持 `{name}`、`{index}`、`{ext}`、查找替换、起始序号、补零位数、逐项预览、重复/空名称校验和原子批量接口。
- 视频管理窗口新增独立预览播放器，预览不会改变房间当前播放、队列或全员进度。
- 正式账号可在个人资料修改登录账号名；服务器会迁移房间所有者、权限、好友、聊天、媒体、申请、审计和在线会话，旧账号立即失效。内置 `admin` 不可改名，游客需先转正式账号。
- 退出房间或退出登录时，服务器在响应前同步清理在线成员和会话，新设备可以立即重新登录。
- 拒绝使用协议后会话、Socket 和游客退出标记全部清理，登录页显示“未登录”，不会再出现“自动重连”或“已以游客身份进入”误报；下次登录会自动重建连接。
- 邮件设置选择内置模板后立即更新主题、编辑区和安全预览，“应用模板”按钮仍可用于再次应用。
- 内置超级管理员的房间额度显示为 `n/99999`。

## 版本与构建

- `package.json`、Android `versionName/versionCode`、Electron、Windows、macOS、Docker、独立服务端和下载文件名统一为 `v2.2.5` / `20205`。
- 发布清单仍为 26 个维护者真实资产加 GitHub 自动源码归档 2 个，共 28 个可见文件。17 个应用必须由最终 Tag 源码重建，Node.js/cloudflared 9 项必须按官方来源和 SHA-256 核验。
- 当前工作站无法替代 macOS runner 和小米 14/HyperOS 真机；这些验证以 GitHub Actions 和设备证据为准。

完整下载表、永久使用说明、测试门禁和已知限制见 [v2.2.5 发布说明](https://github.com/xuange6610/SyncWatch/blob/main/docs/release-notes-v2.2.5.md)。
