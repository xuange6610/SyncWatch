# v2.3.1 更新公告

## 重点变化

1. 屏幕共享默认携带 Windows 系统声音，并按当前设备能力请求原生分辨率、最高刷新率和极致画质。
2. 共享音频优先 WebRTC，PCM 只作延迟回退；新的抖动缓冲和 Opus 参数针对音乐播放的断续问题优化。
3. 房间实时显示共享者、媒体/文件名和进程名；停止共享后状态立即消失。
4. 修复 Android 旧端口与过期数据锁导致的启动失败。
5. 修复 925–1450px 桌面顶栏拥挤和中文菜单逐字换行，移动端下拉菜单保持完整可滚动。

## 验收说明

v2.3.1 的正式资产必须从最终 Tag 重新构建，并完成 Windows/Android 启动、核心流程、版本、平台、大小和 SHA-256 核对后才可上传。历史 Release、Tag 和资产保持不变。
