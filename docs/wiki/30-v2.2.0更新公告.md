# SyncWatch同步观影 v2.2.0 更新公告

v2.2.0 从 v2.1.9 升级登录安全、移动端可用性、媒体处理、公网访问可观测性和多端同步可靠性，并提供 Windows、Android、macOS 与浏览器客户端。

本次更新包括：本机免密管理员入口与 admin 会话上限、游客权限收紧、账号可用房间提醒、服务器网卡选择和公网根地址教程、cloudflared 偏好持久化与启动进度、媒体自动处理加速/停止、扫描房间批量删除、日志账户模糊搜索、Windows 通知、新服务器入口，以及手机登录、观影、聊天、AI/API、语音、资料卡、全屏和滚动条布局优化。

完整变更、26 个下载直链、SHA-256、架构边界、首次启动和已知限制见仓库的 [v2.2.0 正式发布说明](https://github.com/xuange6610/SyncWatch/blob/main/docs/release-notes-v2.2.0.md)；正式下载页为 [GitHub Release v2.2.0](https://github.com/xuange6610/SyncWatch/releases/tag/v2.2.0)。

第一次使用请以 `admin` / `admin888` 登录并立即修改默认密码。升级前先停止服务并备份整个 `SyncWatch同步观影-Data/`。

当前没有小米 14/HyperOS 真机验证；macOS 包来自真实 runner，但未使用 Apple Developer ID 签名或公证。不要把模拟器、源码契约或未签名构建描述成对应设备已经通过。
