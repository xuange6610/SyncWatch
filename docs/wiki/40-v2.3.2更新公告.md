# v2.3.2 更新公告

本版本修复管理中心刷新、房间上传限制和视频封面问题，并改善屏幕共享在隧道网络下的音频发送策略。

- 管理中心刷新失败时不再误报成功；服务器设置加载减少重复请求与全量会话扫描。
- 房间设置显示当前房间名称/房间号；上传大小与时长都为 `0` 时表示完全不限。
- 视频管理封面失败会使用当前会话令牌重试，仍失败时显示文件图标。
- “选项”菜单新增快捷键查看/设置入口；手机网页按视频、控制项、设置的顺序排列。
- 手机登录音乐面板可展开查看曲目，移动网页隐藏不可靠的 F 键/Ctrl+0 快捷键。
