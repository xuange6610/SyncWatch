# 成员连接与同步播放

## 局域网

房主保持服务器运行，在服务器窗口或设置页分享局域网地址。成员与房主连接同一 Wi-Fi，在浏览器、Windows 客户端或 Android 中输入地址。先完成登录和入房，再测试播放控制。

## 公网

公网地址必须使用 HTTPS。可以使用内置 Cloudflare Tunnel，也可以使用自己的 HTTPS 反向代理。公网打开后，房间密码和管理员密码仍然有效；不要公开管理链接、令牌或日志。

v2.2.6 起，只有真实服务器应用窗口显示“局域网服务”地址。Electron 客户端、Android 和普通浏览器即使使用超级管理员账号也不显示 LAN IP；从 Tunnel/公网访问时，分享只使用当前 HTTPS Origin 或服务器配置的公网根地址，并只展示一个地址。没有可信公网地址时分享入口保持空置，不回退内网 IP。

v2.2.3 起，内置 cloudflared 通过本机回源时会按可信代理链恢复不同公网客户端的真实来源 IP，不再把所有游客都记成同一个穿透 IP。外置 Nginx、Docker 或 frp 必须精确配置 `SYNCWATCH_TRUSTED_PROXIES`；服务端从 `X-Forwarded-For` 右侧向左剥离可信 hop，不可信直连提交的代理头会被忽略。同一真实 IP 仍只允许一个活动游客会话；占用提示可由超级管理员在“统一界面文案”修改 `login.guestIpOccupied` 并实时生效。

## 同步机制

房主点击播放、暂停、跳转或倍速时，客户端发送操作意图；服务器更新权威房间状态并通过 Socket.IO 广播。成员端使用服务器时间、网络延迟和本地缓冲计算偏差，超过阈值才校正播放器，因此普通网络抖动不会造成频繁跳动。

“允许快进/拖动进度”可以独立于播放/暂停授权；有播放控制权限的成员调整倍速后，所有成员使用同一房间倍速。房主可设置片头/片尾秒数，选择影片或队列续播时自动从片头结束处开始，接近片尾时按当前队列模式进入下一项。房主或管理员还可向指定成员发清晰度切换申请，对方确认后只改变自己的播放源。

双击画面进入全屏后，弹幕保持在媒体上层。全屏再次双击只打开边看边聊和控制层，不触发播放或暂停；按 `F2` 或回车可以直接打开边看边聊并聚焦输入框，按 `L` 锁定或解锁画面操作，桌面 `F12` 可切换观影全屏。全屏期间不显示普通 Toast、通告、位置/授权窗或其他模态框，退出后再显示待确认申请。浏览器缩放、高 DPI、窄视口和低高度下，聊天操作区可滚动，退出全屏入口保持可达。

“简洁模式”按账号隐藏片库、成员、公告、聊天和高级按钮，只保留核心观影控制，并只接收成员进出房和进度调整通知。“仅聊天”只显示用户聊天；弹幕设置可调整该账号看到的颜色和字号。这些偏好保存在服务器账号资料，不影响其他成员。

### 同步网址与实时共享网页画面

“同步网址（各端独立浏览）”先由服务端校验 HTTP/HTTPS URL，再保存地址、标题、操作者和 revision；晚加入、重连或切换设备会恢复同一权威地址。每个客户端仍在 sandbox iframe 中独立请求目标站点，登录 Cookie、地区、广告、A/B 测试、CSP、`X-Frame-Options` 和跨域脚本会造成画面或交互差异，父页面不能跨域同步目标站的点击与滚动。

如果目标是“所有人看到主持人操作后的完全同一画面”，使用“实时共享网页画面”，选择浏览器标签页或窗口进行屏幕捕获。不要为实现跨域控制而关闭目标站或反向代理的安全头。

### “同步正常 / 网络波动 / 连接中断”怎么判断

v2.2.3 起，视频缓冲和 Socket.IO 控制通道分开判断。客户端在前台时每 4 秒最多发起一个顺序探测：单次延迟尖峰、一次超时、视频 `waiting/stalled` 或其他成员短暂重连不会直接显示“网络波动”；只有连续 3 次延迟超过 500 毫秒或超时才降级，连续 2 次健康样本后恢复。页面或 Android WebView 进入后台时不启动新探测，后台返回的旧结果也不会计入；回到前台后会重新建立质量基线。“连接中断”则表示本机 socket 确实断开，仍会立即显示并进入重连流程。

探测结果带递增序号，旧响应和上一连接周期的迟到结果会被忽略；质量遥测不会在重连后补发旧数据。超过 32 MiB 的媒体使用 8 MiB 有界开放 Range；媒体网络错误或连续 12 秒无进展时最多执行 5 次渐进恢复，离线期间暂停消耗次数，原画仍失败且服务器已有流畅版时再自动降级。这个机制修复的是“影片放着放着因后台节流、频繁续段或偶发探测而误报/停顿”，不会把真实家庭上行不足、Tunnel、VPN/TUN 或运营商抖动伪装成正常。遇到持续提示时，展开成员明细查看“持续高延迟 · 正在恢复”，再检查服务器上行、客户端下载速度、WebSocket 和媒体 Range。

## 同步阅读小说与文本

文本、TXT、Markdown 和 JSON 等安全文本也使用房间权威状态同步。先在影片库选择已审核的文本文件，房主或拥有控制权的成员滚动阅读、输入页码或点击上一页/下一页；客户端通过 `text-reading-update` 提交当前文件 ID、精确 UTF-16 `characterOffset` 锚点（同时保留 0 到 1 的 `position` 和页码兼容字段），服务器校验后以递增 `revision` 广播 `text-reading-state`。成员端和晚加入/重连客户端始终保留同一个逻辑偏移，本地 Range 只把该字符所在的视觉行滚到阅读区顶部；屏幕尺寸变化会重新校准，但不会把桌面或手机各自的换行行首回写到房间状态。

没有控制权的成员可以阅读和跟随，不能覆盖房间进度。切换文件、删除当前文件或清空画面会清除旧文本位置，防止上一部小说的进度串到下一部。服务器默认允许安全文本上传，管理员可在“服务器设置 → 房间与上传 → 上传限制”关闭；单个文本文件上限为 10 MB，二进制伪装文本会被拒绝。

## 成员头像与资料

- 单击成员头像仍打开该成员资料，不会因为新增大图预览而失效。
- 桌面双击头像或触摸端在 420 毫秒内快速点击两次会打开大图预览，并取消尚未执行的单击，避免先弹出成员资料。
- 成员延迟、同步率等状态更新可能重绘成员列表；单击等待期间即使原头像节点已被替换，也会按账号找到新节点后继续打开资料。
- 大图预览可用关闭按钮、点击遮罩或 Escape 关闭，关闭后焦点尽量回到原控件。

## 常用操作

- 房主可以锁定播放控制，成员需要申请控制权。
- 媒体不兼容时等待 FFmpeg 生成 H.264/AAC 兼容版本。
- 播放不同步时先区分状态：偶发缓冲不等于“网络波动”；持续显示“网络波动”时等待至少两个健康探测恢复，真实“连接中断”则先完成重连，再从队列重新开始。
- 屏幕共享、麦克风和桌面音频需要浏览器或系统权限。
