# 管理中心逐按钮教程

打开 GitHub Pages 的 [3D 管理中心](https://xuange6610.github.io/SyncWatch/management-center.html)，每个模块卡片都进入独立 HTML 教程。每个模块都遵循：打开入口 → 修改字段 → 保存 → 用普通账号验证。

## 11 个模块

| 模块 | 核心按钮 | 验证方法 |
| --- | --- | --- |
| 房间与上传 | 新建房间、选择文件、批准上传、加入队列 | 成员能看到媒体并跟随播放 |
| 全部房间 | 进入、置顶、编辑、关闭/删除 | 成员和聊天属于当前房间 |
| 成员与权限组 | 设备详情、授予/收回控制权、踢出、封禁 | 普通账号只能执行被授予的动作 |
| 聊天与记录 | 切换频道、筛选、导出、删除/清空 | 导出内容已脱敏，操作出现在日志 |
| 账户与注册 | 审批注册、重置密码、撤销会话、邮箱验证 | 旧令牌失效并需要重新登录 |
| 用户申请中心 | 查看详情、同意、拒绝、填写原因 | 申请状态变化并可在日志回溯 |
| 账户权限等级 | 新建等级、额度、功能开关、分配 | 测试账号的边界符合策略 |
| 通知/通告设置 | 编辑、预览、发送、撤回 | 桌面和手机端都能正确换行 |
| 邮件设置 | SMTP、TLS、应用专用密码、测试邮件 | 收到邮件且授权码不明文显示 |
| 日志中心管理 | 时间、类型、操作者、展开、导出 | 导出前删除令牌、IP 和邮箱 |
| 服务器设置 | 端口、Tunnel、可信代理 IP、统一界面文案、导入/导出 | HTTP、Socket.IO、真实客户端 IP、游客提示和媒体 Range 都通过 |

逐模块图文页面： [room-upload](https://xuange6610.github.io/SyncWatch/modules/room-upload.html)、[members-permissions](https://xuange6610.github.io/SyncWatch/modules/members-permissions.html)、[server-settings](https://xuange6610.github.io/SyncWatch/modules/server-settings.html)。其他模块可从管理中心卡片进入。

v2.2.3 的服务器设置新增两项需要逐端验证的行为：内置 cloudflared 会自动按可信本机回源恢复真实客户端 IP，外置代理使用 `SYNCWATCH_TRUSTED_PROXIES` 声明精确 IP/CIDR；“统一界面文案”中的 `login.guestIpOccupied` 控制同 IP 游客占用提示，保存后实时广播并直接用于后续服务端错误响应。
