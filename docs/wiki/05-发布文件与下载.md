# 发布文件与下载

下表是当前可下载的 v2.2.0 正式资产。v2.2.3 仍是源码候选，尚无可下载文件；其 17 个应用资产必须从最终 Tag 重新构建并完成启动、闭包、平台/架构、大小和 SHA-256 验证，9 个 Node.js/cloudflared 文件须另行核对官方来源与哈希后，才能一次性上传完整 26 项。

| 文件 | 用途 | 边界 |
| --- | --- | --- |
| `SyncWatch-Experience-Client-Portable-v2.2.0-x64.exe` | 体验版；Windows 成员 | 只加入已有服务器，不启动服务端 |
| `SyncWatch-Standard-Server-Portable-v2.2.0-x64.exe` | 标准版；Windows 房主 | 绿色便携运行，内置 Electron/Node、媒体工具和 cloudflared |
| `SyncWatch-v2.2.0-Full-Offline-Installer-x64.exe` | 完整版；Windows 房主 | 可选安装目录、快捷方式、卸载入口和完整 Windows 服务端；内嵌 Windows、Android 与 macOS 离线下载文件 |
| `SyncWatch-v2.2.0-Full-Offline-Portable-x64.exe` | 完整版；Windows 房主 | 无需安装的独立 EXE；功能与内嵌内容和安装完整版一致 |
| `SyncWatch-Full-Offline-macOS-v2.2.0-x64.dmg/.zip` | 完整版；Intel Mac 房主 | x64 完整服务端、cloudflared 和全平台离线下载中心 |
| `SyncWatch-Full-Offline-macOS-v2.2.0-arm64.dmg/.zip` | 完整版；Apple 芯片 Mac 房主 | arm64 完整服务端、cloudflared 和全平台离线下载中心 |
| Android APK | Android 成员或受支持的手机服务器 | arm64-v8a、armeabi-v7a、x86_64；需要系统权限 |
| macOS DMG/ZIP | Intel 或 Apple Silicon | 选择 x64/arm64，对应包由真实 macOS Actions 构建 |
| 独立服务器 ZIP | Node/Docker/长期部署 | 需要 Node.js 22+，包含生产依赖和启动脚本 |
| cloudflared 独立工具 | 临时或固定公网 Tunnel | [Cloudflare 官网](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) · [官方 Release 下载](https://github.com/cloudflare/cloudflared/releases/latest)；只在手工诊断或部署时使用 |
| Node.js 环境包 | 源码开发、独立服务器 | [Node.js 官网](https://nodejs.org/) · [官方下载](https://nodejs.org/en/download)；正式 Windows EXE 已内置，无需重复安装 |

体验版不包含服务器；标准版是小体积绿色服务器；完整版同时提供 Windows 安装 EXE、Windows 独立 EXE 和 macOS 双架构 DMG/ZIP，并把真实 Android APK 和其他平台发布文件作为离线下载资源装进包内。Windows 不会执行 APK 或 macOS 程序，房主启动服务后由对应设备下载并安装自己的平台文件。

下载后按 Release 页的 SHA-256 校验。Windows 使用 `Get-FileHash 文件名 -Algorithm SHA256`，macOS/Linux 使用 `shasum -a 256 文件名`。正式 Windows EXE 不需要用户安装 Node.js；Node 安装包只用于源码开发和独立服务端。
