体验版不包含服务器；标准版是小体积绿色服务器；完整版同时提供 Windows 安装 EXE、Windows 独立 EXE 和 macOS 双架构 DMG/ZIP，并把真实 Android APK 和其他平台发布文件作为离线下载资源装进包内。Windows 不会执行 APK 或 macOS 程序，房主启动服务后由对应设备下载并安装自己的平台文件。

下载后按 Release 页的 SHA-256 校验。Windows 使用 `Get-FileHash 文件名 -Algorithm SHA256`，macOS/Linux 使用 `shasum -a 256 文件名`。正式 Windows EXE 不需要用户安装 Node.js；Node 安装包只用于源码开发和独立服务端。

v2.2.7 公告、主页、Wiki 和页面“关于”必须使用同一仓库与版本入口。纯 Node 控制台包不承诺 Electron 菜单，只通过 `--help`、`--open-browser` 和运行信息文件进入管理；这不改变 26 项正式 Release 清单。
