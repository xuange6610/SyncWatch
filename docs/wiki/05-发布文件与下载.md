| Node.js 环境包 | **服务器环境** | 源码开发、独立服务器 | [Node.js 官网](https://nodejs.org/) · [官方下载](https://nodejs.org/en/download)；正式 Windows EXE 已内置，无需重复安装 |

体验版不包含服务器；完整便携版是 Windows 房主使用的独立服务器，并内含 Windows/Android 离线资源。Windows 不会执行 APK，成员请在对应设备上安装自己的客户端。

下载后按 Release 页的 SHA-256 校验。Windows 使用 `Get-FileHash 文件名 -Algorithm SHA256`。正式 Windows EXE 不需要用户安装 Node.js；Node 安装包只用于源码开发和独立服务端。

v2.4.0 公告、主页、Wiki 和页面“关于”必须使用同一仓库与版本入口。纯 Node 控制台包不承诺 Electron 菜单，只通过 `--help`、`--open-browser` 和运行信息文件进入管理；当前正式清单为 8 个上传资产加 2 个源码归档。
