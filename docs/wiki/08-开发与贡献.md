# 开发与贡献

## 环境

源码开发推荐 Node.js 24 LTS（最低 22）、Git、PowerShell 7 和 Android Studio/SDK（移动端）。当前发布范围只构建 Windows 与 Android 成品。

```bash
git clone https://github.com/xuange6610/SyncWatch.git
cd SyncWatch
npm ci
npm test
npm start
```

Windows 开发备用入口是仓库根目录 `start-syncwatch.bat`；普通用户不应使用它，正式用户直接下载 EXE。

## 分支和 Pull Request

从 `main` 创建短分支，提交使用动词开头的简短中文或英文说明。修改服务端运行相关代码时至少运行 `npm test` 和对应专项测试；修改发布、隐私或文档时运行 `npm run test:repo` 与隐私检查。提交 PR 后由 Actions 检查，维护者审核后合并，外部贡献不会直接覆盖正式源码。
