# v2.2.7 更新公告

v2.2.7 同版本更正版重点修复登录并发、访问记录、管理员客户端模式申请、PC 端简洁模式和全屏交互问题。[GitHub Release v2.2.7](https://github.com/xuange6610/SyncWatch/releases/tag/v2.2.7) 已完成最终 Tag 源码真实构建、Release API 的 10 个维护者资产、页面共 12 个文件、Latest 与远端哈希回读。

## 本轮改动

### v2.2.7 本轮补充修复

- 房主始终可以调整房间共享倍速；其他成员仍按 `control` 权限控制。
- “跳过片头和片尾设置”已加入成员与权限组权限列表，权限名为 `skipSettings`。授予后，成员可在房间工具中打开并保存自动跳过设置；未授权提交会被服务端拒绝。

- 下载中心已移除 macOS 新包入口；Windows 完整便携版增加“推荐”高亮，历史版本仍保留在各自 Release。
- 点击房间列表、局域网扫描或“我的房间”的加入按钮会立即提示，成功通知包含房间名称、房间号、正式/临时类型和房主。
- 全屏锁定与解锁显示 `🔒/🔓` 图标并在画面内提示状态；顶部当前主题字段支持双击进入主题设置。
- 管理中心先显示可操作窗口，再异步读取服务器设置，减少打开时的卡顿；“我的房间”卡片强化名称、编号、房间类型、房主、密码状态、在线人数和备注层级，窄屏可换行。

### 追加复核修复

- 新版完整离线包不再内嵌 macOS 安装包，下载中心和 Wiki 只列 Windows/Android 新资产；历史 Release 仍按规则保留。
- 房主进入自己的房间后，顶部“房间设置”按钮直接打开管理中心房间模块；加入房间成功会显示独立可读提示。

### 网页共享、视频封面与继续观看

- “同步网址”启动前自动清空原视频画面；网址由各端独立加载。要获得一致实时画面，请使用标签页/窗口共享。
- 本地视频封面从中段随机截图生成，视频管理系统支持批量随机重做封面。
- 未看完的视频会保存账户级进度，下次选择时可确认继续播放。
- 顶部房间状态整栏双击即可打开主题设置；服务器设置内容采用延迟布局，减少首次打开卡顿。
- 全屏锁定/解锁的锁图标、文案和画面内提醒保持同步；管理员密码仍只提供安全重置，不显示明文。
- 账户菜单新增“房间设置”，并在“我的房间”自有房间卡片提供同名入口；进入后会切换到目标房间，房主管理中心只显示房间与上传、成员与权限组、聊天与记录三个模块。
- 登录页在短窗口、浏览器缩放和高 DPI 下从顶部开始并由页面统一滚动，底部客户端下载、其他登录方式和版本信息均可向下查看。

- 简洁模式改为控制真实 `.workspace` 容器，侧栏隐藏后使用单列剧场布局；聊天记录和实时语音采用稳定 Grid，不再互相挤压。
- 原生/伪全屏共用退出清理流程，清除通知、定时器、手势、旋转、缩放、亮度和锁定状态，并支持 WebKit 全屏事件。
- 全屏双击只打开“边看边聊”，不触发暂停或播放；全屏按 `F2` 可呼出聊天并聚焦输入框。
- 全屏首次提示按账号和日期记录，每天最多一次；可选择永远不提示，账号安全设置可恢复提示。
- 全屏左上角增加锁定按钮。锁定后禁止画面误触播放/暂停和进度拖动，但仍能解锁、呼出聊天和退出全屏。
- 全屏左半区上下滑动调媒体亮度，右半区上下滑动调播放器音量；手势不会发出房间播放命令。
- 画中画失败不再在一次点击中抢用两个用户激活 API；Document PiP 失败后提供再次点击的系统 PiP 重试动作。
- Android 构建校验已同步检查包内 `versionName 2.2.7`，不会再因沿用旧版本校验导致发布包被误判失败。
- 达到账号设备上限时可以提交多设备登录申请；内置 `admin` 可批准、拒绝或撤回授权，撤回后恢复服务器默认上限。
- 服务器设置记录登录页访问，并提供普通账号设备上限、单 IP 游客上限、账号/IP 白名单和 IP 黑名单快捷操作。
- 管理员可向指定用户、当前房间或全服务器发送关闭普通通知、简洁模式或专业模式申请；用户确认后才应用，离线用户下次登录补投，管理员可取消待确认申请。
- 协议拒绝会完整退出且停止自动重连；好友资料卡、50 种立方体预设、未登录隐藏服务器设置、正式/临时房间类型提示和“只退出房间”主按钮同步修正。

## 使用和验证

1. 在房间顶部打开简洁模式，确认播放器占满主列，刷新后账号偏好仍保留。
2. 点击或双击全屏画面，确认双击不会暂停；按 `F2` 检查聊天输入框获得焦点。
3. 首次进入全屏会出现轻量提示；同一天再次进入不重复出现。到账号安全设置可恢复提示。
4. 点击锁按钮后拖动进度或点击画面不会改变播放状态；左、右半区垂直滑动分别只改变亮度和本地音量。
5. 画中画失败时点击“改用系统画中画”，不要在同一点击事件中连续调用两个 API。
6. 使用第二台测试设备触发并发限制，提交申请后由 `admin` 批准，再验证第二设备可以登录；取消授权后第三设备应再次被限制。
7. 从管理中心向指定用户、当前房间和全服务器发送三种客户端模式申请，分别验证同意、拒绝、管理员取消和离线补投。

本地测试覆盖登录并发申请批准/撤回、登录页访问记录、客户端模式申请确认/拒绝/离线补投/取消，以及桌面/移动视口、简洁模式、F2、全屏锁定、亮度手势和退出清理；Android 小米 14/HyperOS、完整 10 个维护者资产仍以 Actions/真实设备证据为准，macOS 新包不在本版本范围内。

## 发布边界

- `dist/` 必须由最终 Tag 直接形成 12 个非空文件：10 个维护者资产加两个源码归档。
- Windows 4、Android 1 从最终 Tag 重新构建；Node.js 2 和 cloudflared 3 按官方来源或已核验缓存核验；macOS 新包停用。
- 同版本替换时先保留旧资产；新 10 项以临时名上传并完成远端哈希回读后再切换正式名称，失败则恢复旧集合，不能先清空 Assets。
- v2.2.5、v2.2.4 及更早 Release、Tag 和资产保持不变。

# v2.2.7 追加修复：网页共享、视频封面与继续观看

- “同步网址”会先清空当前房间视频画面，再把地址同步给所有客户端；各端独立加载网页。需要同一实时画面时，请选择“实时共享网页画面”并共享浏览器标签页或窗口。
- 上传视频默认从中段随机截图作为封面；在“我的影片 → 上传视频管理系统”中勾选视频，点击“批量随机封面”即可批量重做封面。
- 影片未播放完即关闭、退出或异常中断时，观看进度会保存到账户。下次选择该影片会出现“继续上次观看”提示，确认后从保存位置恢复并同步房间进度。
