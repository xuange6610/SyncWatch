# SyncWatch同步观影 v2.3.4 发布说明

# v2.3.4 更新公告

## 本轮修复

- 修复 Android/手机网页进入全屏后控制层被应用顶栏或播放器层遮挡，导致控件不可见、不可点击的问题；全屏时隐藏外围页面 chrome，保留可操作的显示界面按钮和安全区适配。
- 手机全屏控件不再自动淡出，方向、缩放、退出全屏和边看边聊入口保持可触控；全屏舞台使用主题背景，避免出现额外的黑色遮罩层。
- 扩大移动端聊天表情面板的可视高度并启用独立纵向滚动，确保全部分类的最后几行可以继续下滑看到。
- 修复 Android 反复点击“观影 / 片库 / 聊天 / 成员”时聊天模块和模块切换栏可能建立超宽网格轨道的问题，限制内容宽度并阻止长消息撑大页面。
- 按本轮确认取消手机进入全屏时的自动横屏；全屏保持当前设备方向，仍保留竖屏、横屏和自动横屏三个手动控制选项。

## 验收与发布边界

- 已通过 `node --check public/js/app.js`、布局回归、移动端 Chromium UI 冒烟；覆盖 390×844、375×667、812×375 和 844×390 视口，并对全屏、表情滚动、模块来回切换进行了截图检查。
- Windows、Android 和 Windows 上的 Node.js/cloudflared 官方工具按发布清单构建与核验；正式 Release 必须有 8 个维护者资产和 2 个 GitHub 源码归档。
- 所有 SyncWatch 应用资产均须由最终 v2.3.4 Tag 对应源码真实重建，完成版本、平台、启动、闭包、大小和 SHA-256 核验后才能上传。
