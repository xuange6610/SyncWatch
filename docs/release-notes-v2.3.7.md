# SyncWatch同步观影 v2.3.7 发布说明

## 更新公告

- 修复顶部“同步正常”状态区域双击时误打开“界面风格”设置；该区域现在仅用于显示连接状态。
- 修复顶部“服务端口”区域双击时误打开“界面风格”设置；端口显示保持只读，不再触发主题窗口。
- 保留房间名称重命名、在线成员人数上限编辑的双击功能，并隔离它们与顶部主题快捷入口的事件冒泡。
- 延续 v2.3.6 的旧数据目录兼容、默认端口 `20311`、端口冲突提示、当前上网物理网卡自动选择和权限控制修复。
- 同步更新 Windows、Android、Web、README、部署教程、Pages/Wiki 源文档和发布契约中的版本号与下载链接。

## 发布资产与验收边界

- 正式 Release 包含 8 个维护者资产和 GitHub 自动生成的 2 个源码归档；Windows/Android 应用包必须由最终 `v2.3.7` Tag 对应源码真实重建。
- 发布前完成源码回归、Windows/Android 启动与核心流程、包内源码闭包、版本、平台/架构、非空大小、SHA-256 和 GitHub Release 下载回读核验。
