账户与注册

管理注册账号、登录设备、编号策略、注册申请、建房额度、白名单和封禁状态。

适用权限：超级管理员或通过服务器管理员验证的账号截图：5 张真实 v2.2.0 界面
开始逐步配置查看实机图集

怎样打开这个模块

入口会随账号权限变化。普通成员看不到服务器管理员专属模块，这是正常的服务端权限结果。

  • 登录超级管理员账号
  • 打开管理中心
  • 点击“账户与注册”
  • 刷新账号和申请数据

从打开到验证的完整步骤

一次只修改一类设置；看到保存成功后，再使用普通测试账号验证最终结果。

  1. 搜索目标账号：按账号、显示名、邮箱、备注或 IP 搜索，并按在线状态和姓名排序。
  2. 切换视图：卡片适合快速操作，紧凑列表适合大量账号，表格适合对比字段。
  3. 打开账号总览：查看全部注册账号和在线状态，再跳转到指定账号明细。
  4. 处理账号资料：可修改显示名、管理员备注、绑定邮箱和账户编号；登录账号本身保持稳定。
  5. 重置密码与会话：设置临时密码后撤销旧会话，通知用户登录后再次修改。
  6. 配置编号规则：设置前缀、分隔符、数字位数和下一个编号，只影响新编号生成。
  7. 审批注册与额度：核对来源、邮箱和理由后批准或拒绝多账号注册及建房额度申请。
  8. 维护白名单和封禁：白名单仅用于明确可信来源；封禁前确认账号、设备和原因。
  9. 查看账户日志：按注册、登录、注销分类检查异常，并在导出前脱敏。

完整操作示例

用户更换设备且忘记密码：搜索账号，核对显示名、邮箱和最近设备；重置为临时密码并撤销全部会话，通过安全渠道通知用户，最后在账户日志确认旧会话不能继续使用。

常见误区

  • 根据显示名而不是登录账号操作。
  • 把注册 IP 或邮箱截进公开图片。
  • 批量操作前没有清除搜索条件。
  • 用网页登录密码代替临时重置流程。

全部按钮、字段与结果

字段名称以 v2.3.5 源码为准；截图仍标注其实际采集版本，不用旧截图冒充新版本证据。不同平台、账号角色或功能开关可能隐藏不适用的项目。

按钮 / 字段用途、结果与注意事项
搜索/在线筛选/排序在大量账号中找到正确对象。
视图模式卡片、紧凑和表格三种密度。
账号总览统一查看注册账号并跳转明细。
账户日志筛选注册、登录、注销事件。
仅看超级管理员快速审核高权限账号。
批量重置密码对所选账号应用默认重置密码。
批量禁止建房/删除高风险批量账号操作。
账户编号规则控制新账户的管理编号格式。
多账号注册申请审批同一用户的额外账号。
建房额度申请调整可创建房间数量。
注册 IP 白名单允许指定来源按策略注册。
封禁列表查看和解除服务器封禁。

每张图都从真实临时服务器的 账户与注册 页面采集，没有复用其他模块截图。点击图片可查看原始尺寸，并用方向键切换。

保存后必须这样验证

管理员页面显示成功只是第一层；还要用目标角色、目标设备和目标网络重复真实操作。

  • 旧令牌在撤销会话后立即失效。
  • 编号规则只改变管理编号，不改变登录名。
  • 审批结果和原因进入日志。
  • 普通管理员看不到超出其范围的敏感信息。
