全部房间

跨房间查看成员、设备、播放和存储状态，并对选中房间执行批量策略。

适用权限：超级管理员或通过服务器管理员验证的账号截图：5 张真实 v2.2.0 界面
开始逐步配置查看实机图集

怎样打开这个模块

入口会随账号权限变化。普通成员看不到服务器管理员专属模块，这是正常的服务端权限结果。

  • 登录超级管理员账号
  • 打开“管理中心”
  • 点击“全部房间”
  • 先刷新再筛选目标

从打开到验证的完整步骤

一次只修改一类设置；看到保存成功后，再使用普通测试账号验证最终结果。

  1. 刷新房间数据：点击“刷新房间”，读取当前在线房间、房主、成员、设备和播放状态。
  2. 搜索并确认范围：按房间号、名称、房主或备注搜索；批量操作前确认列表只包含目标房间。
  3. 查看当前房间标记：当前所在房间会有提示，切换前记住原房间，便于完成后返回。
  4. 进入目标房间：使用进入/切换功能后，重新核对成员、聊天、文件和播放器状态都属于新房间。
  5. 查看媒体：打开房间影片预览，检查媒体名称、上传者和状态；删除前确认没有正在播放。
  6. 设置空间上限：勾选一个或多个房间，填写 MB 上限并应用；0 表示不限制。
  7. 执行批量策略：可批量停止播放、要求密码、封禁、改名或改房间号；每次只做一种操作并查看结果。
  8. 永久删除前备份：删除房间会影响成员、媒体和记录；先导出数据并通知房主。

完整操作示例

服务器准备维护：搜索“临时活动”，全选筛选结果，先批量停止播放并通知房主；确认备份后设置新的空间上限。不要把正式家庭房间混入同一批次。

常见误区

  • 未搜索就直接全选全部房间。
  • 改房间号后仍分发旧链接。
  • 把停止播放误认为删除媒体。
  • 没有备份就永久删除。

全部按钮、字段与结果

字段名称以 v2.3.0 源码为准；截图仍标注其实际采集版本，不用旧截图冒充新版本证据。不同平台、账号角色或功能开关可能隐藏不适用的项目。

按钮 / 字段用途、结果与注意事项
搜索房间按房间号、名称、房主和备注模糊匹配。
全选当前列表只选择筛选后的结果，批量前仍需逐项复核。
空间上限为所选房间统一设置容量，0 表示不限。
批量停止播放停止所选房间当前媒体，不删除文件。
批量要求密码提示房主为房间补设访问密码。
批量封禁阻止目标房间继续使用，适合明确违规情形。
批量改名/改房间号统一整理标识；修改后旧邀请地址可能失效。
批量永久删除清理房间及关联数据，操作不可逆。
房间媒体预览跨房间查看、删除或禁止同名影片再次上传。

保存后必须这样验证

管理员页面显示成功只是第一层；还要用目标角色、目标设备和目标网络重复真实操作。

  • 搜索结果与目标范围一致。
  • 切换房间后主界面上下文完整更新。
  • 批量操作的成功/失败数量与选择数一致。
  • 日志中心出现操作者、目标房间和结果。
