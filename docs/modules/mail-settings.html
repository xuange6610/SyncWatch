邮件设置

配置 SMTP、验证邮件功能、模板、测试收件人与验证码记录，敏感授权码不会明文回显。

适用权限：超级管理员或服务器管理员截图：5 张真实 v2.2.0 界面
开始逐步配置查看实机图集

怎样打开这个模块

入口会随账号权限变化。普通成员看不到服务器管理员专属模块，这是正常的服务端权限结果。

  • 准备邮箱应用专用授权码
  • 打开管理中心
  • 点击“邮件设置”
  • 先阅读配置教程

从打开到验证的完整步骤

一次只修改一类设置；看到保存成功后，再使用普通测试账号验证最终结果。

  1. 确认服务商参数：从邮箱官方帮助获取 SMTP 主机、端口、TLS/SSL 和授权码要求。
  2. 填写发件账号：填写 SMTP 用户、发件邮箱和发件人名称；授权码不是网页登录密码。
  3. 选择功能开关：按需要启用注册验证、绑定验证、账户找回和管理员找回。
  4. 测试连接：先点击“测试连接”，确认 DNS、端口、TLS 和认证成功。
  5. 编辑邮件模板：选择事件和语言，应用预设后修改主题与 HTML 正文。
  6. 预览模板：检查主题、品牌、验证码/链接占位符和移动端宽度。
  7. 发送测试邮件：输入自己的测试邮箱，选择模板并确认实际收件。
  8. 管理验证码记录：按类型、状态和关键字筛选；只在必要时删除失效记录。
  9. 处理泄露：授权码出现在截图、日志或 Issue 时立即在邮箱后台撤销并更换。

完整操作示例

QQ 邮箱配置：主机 smtp.qq.com、端口按官方要求选择 465 与加密连接，用户名和发件邮箱填完整 QQ 邮箱，密码位置填写应用专用授权码；先测试连接，再向自己的邮箱发送注册验证模板。

常见误区

  • 填写 QQ 网页登录密码。
  • 未测试就开放公开注册。
  • 把授权码复制到 Issue。
  • 模板删除验证码或链接占位符。

保存后必须这样验证

管理员页面显示成功只是第一层；还要用目标角色、目标设备和目标网络重复真实操作。

  • 测试连接成功且没有明文显示授权码。
  • 四类邮件只在对应开关启用时发送。
  • 模板预览与实际邮件主题、链接一致。
  • 日志只记录结果，不暴露授权码和完整验证码。
