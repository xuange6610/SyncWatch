账户权限等级

用账户等级统一管理上传容量、建房数量和说明，并配置观影经验规则。

适用权限：超级管理员或服务器管理员截图：5 张真实 v2.2.0 界面
开始逐步配置查看实机图集

怎样打开这个模块

入口会随账号权限变化。普通成员看不到服务器管理员专属模块，这是正常的服务端权限结果。

  • 登录超级管理员账号
  • 打开管理中心
  • 点击“账户权限等级”
  • 先记录现有等级规则

从打开到验证的完整步骤

一次只修改一类设置；看到保存成功后，再使用普通测试账号验证最终结果。

  1. 查看现有等级：先理解系统等级和自定义等级，避免创建含义重复的策略。
  2. 新建等级标识：组标识用于内部引用，创建后保持稳定；名称用于面向用户显示。
  3. 设置上传上限：单位为 GB，0 表示不限。根据磁盘容量和备份成本设置。
  4. 设置建房数量：0 表示不限；普通用户建议从 1 开始，按需要提高。
  5. 填写等级说明：清楚说明适用人群、能力和限制，避免只写“高级”。
  6. 保存并分配测试账号：先分配给专用测试账号，不要直接改真实管理员。
  7. 配置经验规则：设置每观看一分钟获得的经验，检查各等级门槛。
  8. 重新登录验证：测试账号重新登录后验证上传、建房和等级显示。

完整操作示例

创建“家庭协作”等级：上传上限 50 GB、建房数量 5、说明写明仅供家庭成员；先分配给测试账号并完成上传和建房边界测试，再逐步给真实成员。

常见误区

  • 未测试就一次分配给大量用户。
  • 把 0 误解为零额度。
  • 修改等级后不让客户端重新登录。
  • 等级名称相似导致管理员误选。

全部按钮、字段与结果

字段名称以 v2.2.5 源码为准；截图仍标注其实际采集版本，不用旧截图冒充新版本证据。不同平台、账号角色或功能开关可能隐藏不适用的项目。

按钮 / 字段用途、结果与注意事项
等级列表查看系统和自定义账户等级。
新建等级创建可复用的账户容量策略。
等级标识/名称分别用于内部引用与用户展示。
上传上限（GB）限制账户可使用的上传容量，0 不限。
建房数量限制账户可创建的房间数，0 不限。
等级说明记录策略用途和边界。
每分钟经验控制观看时长转换为经验的速率。
观影等级明细查看等级门槛、名称和进度规则。

5 张对应模块的高清实机图

每张图都从真实临时服务器的 账户权限等级 页面采集，没有复用其他模块截图。点击图片可查看原始尺寸，并用方向键切换。

保存后必须这样验证

管理员页面显示成功只是第一层；还要用目标角色、目标设备和目标网络重复真实操作。

  • 达到上传或建房上限时返回清楚提示。
  • 0 的含义被确认是不限而不是禁止。
  • 经验增长与观看分钟数一致。
  • admin 与超级管理员仍使用服务器级权限。
