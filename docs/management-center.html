管理员第一次操作流程

先完成安全初始化，再开放房间和公网入口。不要跳过密码、房间密码和备份步骤。

  1. 启动并登录运行服务器版，打开本机地址，首次使用 admin/admin888。
  2. 修改密码进入账户与注册，设置唯一管理员密码并确认旧会话已失效。
  3. 创建房间在房间与上传设置名称、人数和房间密码，再邀请成员。
  4. 配置媒体上传影片、等待审核与 FFprobe 分析，必要时等待 FFmpeg 转换。
  5. 验证结果用普通账号加入，检查播放、聊天、权限、日志和备份是否正常。

11 个模块的按钮与结果

每块说明“用途、关键按钮、操作示例和验证结果”。普通成员不会看到服务器管理员专属模块。

01

房间与上传

“新建房间”填写名称、人数、密码；“选择文件”上传媒体；“批准上传”让成员可见；“加入队列”安排播放。

示例：上传后先等状态变为已分析，再点击“加入队列”，播放前确认房间密码。
02

全部房间

“进入”切换房间；“置顶”固定常用房；“编辑”修改规则；“删除”只允许房主或管理员执行。

验证：切换后成员、聊天、文件和播放状态必须属于新房间。
03

成员与权限组

“设备详情”查看连接平台；“授予控制权”临时允许播放控制；“收回控制权”“踢出”“封禁”立即生效。

技巧：先授予控制权测试，再按最小权限建立长期权限组。
04

聊天与记录

切换公聊、私聊、弹幕和语音；“删除”处理单条内容；“导出”保存必要记录；“清空”前必须确认范围。

注意：聊天清理写入操作日志，不能替代媒体和数据备份。
05

账户与注册

“审批注册”“修改显示名”“重置密码”“撤销会话”管理账户生命周期；邮箱验证可按策略开启。

验证：重置密码后旧令牌必须立即失效。
06

用户申请中心

集中处理注册、入房、权限、好友和额度申请；打开详情核对目标后点击“同意”或“拒绝”。

建议：填写处理原因，方便后续在日志中心回溯。
07

账户权限等级

配置等级、经验、上传额度、房间额度和功能开关；保存后用普通测试账号验证边界。

原则：先降低权限验证，再逐项开放，避免一次性给出管理员权限。
08

通知 / 通告设置

编辑登录提示、房间公告和全屏通告；设置范围、颜色、字号和停留时间；“预览”后再“发送”。

技巧：紧急公告写明恢复动作，避免只显示“发生错误”。
09

邮件设置

填写 SMTP、端口、加密方式和应用专用密码；“保存”后点击“发送测试邮件”。授权码不会明文展示。

建议：QQ 邮箱使用应用专用授权码，不要填写网页登录密码。
10

日志中心管理

按时间、类型和操作者筛选登录、权限、媒体、备份和隧道事件；“导出”前先脱敏。

诊断顺序：先看最近一条错误，再看同一时间的网络和权限事件。
11

服务器设置

管理端口、局域网、公网 Tunnel、数据导入导出和网络诊断；公网地址出现后只发给可信成员。

安全顺序：房间密码 → 管理员密码 → 备份 → 诊断 → 启动公网访问。

常见错误的处理顺序

先记录完整报错、平台、版本和操作时间，再按下表处理；不要把含密码、令牌或真实 IP 的日志直接公开。

“运行异常：未找到内置 cloudflared”

确认使用完整服务器包，检查 vendor/cloudflared.exe；源码启动可在服务器设置中点击修复，让程序从 Cloudflare 官方 Release 下载并校验。仍失败时检查 TCP/UDP 443、7844 和 VPN/TUN 分流。

“端口已被占用 / EADDRINUSE”

关闭占用程序或在服务器设置换端口，重新启动后让成员使用新地址。Windows 可运行 netstat -ano | findstr :5000 查看 PID。

成员能打开页面但无法加入房间

先确认房主服务仍在运行，再检查地址、房间密码、Origin/Host 和防火墙。管理员在日志中心确认是否为权限拒绝、房间不存在或令牌过期。

播放不同步或不断跳回

检查成员网络延迟、浏览器缓冲和媒体格式；房主先暂停，等待所有成员连接稳定，再从队列重新开始。HEVC/特殊音轨可等待 FFmpeg 生成兼容版本。

上传卡住、审核后看不到

检查磁盘剩余空间、文件大小策略和上传者权限。日志应同时出现 upload、media-processing 和 approval 事件；不要只复制 config.json，迁移必须带 uploads。

邮件验证码发送失败

确认 SMTP 地址、端口、TLS 和应用专用授权码，点击“发送测试邮件”验证。QQ 邮箱拒绝时检查安全设置；授权码泄露后立即撤销并重新保存。

Android 手机服务器启动失败

安装完整 APK，允许通知、前台服务、存储和网络权限；确认端口没有被其他应用占用。若提示内嵌 Node.js 缺失，不要安装体验版，改用完整包。

导入备份后数据不完整

停止服务器后导入与原备份相同的范围；包含媒体时使用二进制备份。恢复后检查房间、uploads、secrets、聊天和缩略图，再重新启动。

使用技巧与产品优势

先局域网、后公网

首次部署先让两台设备在同一 Wi-Fi 完成登录、建房和同步播放，确认基础链路后再开 Tunnel，排错范围最小。

房间密码是第一道门

公网访问前给所有房间设置密码，并把管理员账号和普通成员账号分开；分享链接时不要附带令牌。

把房主控制权交给可信成员

短时观看可授予控制权，结束后收回；长期协作使用权限组，按最小权限开放上传、公告和媒体管理。

数据目录整体备份

账号、媒体索引、聊天、密钥和上传文件相互关联。迁移前停止服务并复制整个 Data 目录，恢复后再启动。

善用兼容媒体

原片适合高质量播放，浏览器不兼容时切换兼容版本；兼容文件可重建，原片和索引不要随意删除。

自托管的优势

数据留在自己的设备，多端共用同一房间状态，可按需局域网或公网部署；代码、测试、构建和发布过程公开可审查。
