# SyncWatch同步观影 v2.4.0 发布说明

## 更新公告

- 修复 Android/手机端上传视频时被系统厂商选择器误判为“分享视频”并限制五分钟的问题；文件选择改为直接文档选择流程，不再注入任何时长限制，并保留多选和文件夹上传能力。
- 升级上传时长策略迁移版本。所有 v2.3.9 及更早候选配置遗留的 300 秒默认值（包括带旧时间标记的配置）都会迁移为不限；管理员在 v2.4.0 设置中明确保存的限制仍可保留，设置为 0 表示不限。
- 修复短视频封面生成使用固定第 3 秒导致 FFmpeg 截图失败的问题，改为在视频有效时长内安全取帧；缩略图接口禁止缓存瞬态错误，移动端加载失败会自动重试一次。
- 增加触控设备宽视口兜底布局，手机端强制单列房间与播放器，避免桌面三栏轨道把播放器、上传卡片和图片封面推到屏幕右侧。
- 房间分享链接统一改为路径格式（例如 `http://192.168.3.6:20311/DCWDLJ`）；登录页优先解析路径房间号，同时兼容已有的 `?room=DCWDLJ` 旧链接。
- 更新 Android、Windows、Node 独立服务端、Docker 和下载中心的版本标识为 v2.4.0，并同步 README、Pages、Wiki 与发布清单。

## 发布资产与验收边界

- 正式 Release 包含 8 个维护者资产和 GitHub 自动生成的 2 个源码归档，共 10 个可见文件。
- Windows/Android 应用包必须从最终 `v2.4.0` Tag 对应源码重新构建，并完成启动、版本、平台、非空大小、SHA-256 与远端下载回读核验。
- 所有应用资产均须由最终 Tag 源码真实重建，禁止复用旧版本包或使用占位文件。
