# SyncWatch同步观影 v2.3.5 发布说明

## 更新公告

- 新手引导自动提醒只在首次打开时记录完成状态，重启或刷新不会重复弹出；仍可从设置中的“新手教程”手动打开。
- Windows Electron 与独立服务器默认严格监听 `20311`，端口被占用时显示明确错误，不再随机切换导致设置窗口与实际端口不一致；历史数据目录中的旧默认端口会迁移到 `20311`。
- 局域网“自动选择”改为优先系统默认路由对应的当前上网实体网卡，并从可选列表中移除 VPN、TUN、虚拟机、Docker、WSL 等虚拟接口。
- 登录页背景音乐曲目选择会显示服务器已上传的全部歌曲，可直接切换并保存当前曲目。
- 顶部“房间操作”菜单新增“我的房间”和“房间设置”，仅在当前账号具备对应房间管理权限时显示；在线成员人数指标支持双击快速修改当前房间 2-100 人上限。
- 上传限制支持分别设置文件大小下限和上限，并可选择 KB、MB、GB、TB 单位；服务端同步校验范围、32GB 安全上限和下限不大于上限，低于下限的文件会被拒绝。
- 同步更新 Android、Windows、Web、README、部署教程和发布契约中的版本号与端口说明。

## 发布资产与验收边界

- 正式 Release 必须包含 8 个维护者资产和 GitHub 自动生成的 2 个源码归档；Windows/Android 应用包必须由最终 `v2.3.5` Tag 对应源码真实重建。
- 发布前仍需完成 Windows/Android 启动与核心流程、包内源码闭包、版本、平台/架构、非空大小和 SHA-256 核验，并回读 GitHub Release、README、Pages 与 Wiki。
