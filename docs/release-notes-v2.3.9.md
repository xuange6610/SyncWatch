# SyncWatch同步观影 v2.3.9 发布说明

## 更新公告

- 登录页背景音乐改为批量上传、按内容 SHA-256 去重，重复上传同一首音乐不会再重复显示。
- 登录音乐管理列表支持逐曲修改显示名称、选择当前曲目和批量删除，保存后实时同步到所有登录页。
- Android 手机端彻底隐藏实时语音栏及悬浮语音控件，避免无权限功能占用界面空间。
- Android 观影工具第一行固定为“全屏”和“全屏自动锁屏”，共享屏幕、共享电脑音源与悬浮播放按触控网格重新排列。
- 升级旧配置时会清除历史遗留的五分钟视频时长默认值；管理员仍可在上传限制中按需设置具体时长，设置为 0 即不限。

## 发布资产与验收边界

- 正式 Release 包含 8 个维护者资产和 GitHub 自动生成的 2 个源码归档。
- Windows/Android 应用包必须从最终 `v2.3.9` Tag 对应源码重新构建，并完成启动、版本、平台、非空大小、SHA-256 与远端下载回读核验。
- 所有应用资产均须由最终 Tag 源码真实重建，禁止复用旧版本包或使用占位文件。
