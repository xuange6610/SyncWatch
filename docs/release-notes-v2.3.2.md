# SyncWatch同步观影 v2.3.2 发布说明

# v2.3.2 更新公告

## 本轮修复

- 修复管理中心“一键刷新全部申请”在设置读取失败时仍沿用旧数据的问题，并减少管理设置加载时的重复请求与账号会话扫描开销。
- 房间设置显示当前正在修改的房间名称和房间号；上传大小与时长同时设为 `0` 时，公开配置明确表示“不限制”，不再错误显示 10GB。
- 修复视频管理封面在会话令牌过期或图片请求失败时的重试与图标回退，并保留本地视频封面自动生成能力。
- 优化屏幕共享音频在 WebSocket 与轮询隧道下的发送策略，WebRTC 已连通时不再发送冗余 PCM，降低隧道拥塞；维护者资产仍须逐项核对。
- “选项”菜单新增“快捷键”入口，可直接打开账号安全页查看和修改快捷键。
- 手机网页房间调整为视频/播放区优先，选项与房主设置位于视频下方；登录音乐控制支持展开，曲目选择不再被容器裁剪；移动网页停用不可靠的 F 键和 Ctrl+0 快捷键。

## 发布边界

Windows、Android 和 Windows 上的 Node.js/cloudflared 官方工具按发布清单构建与核验。正式发布前必须从 `v2.3.2` 最终 Tag 真实重建应用包，并完成启动、核心流程、版本、平台、大小、SHA-256 与 Release API 回读验证。
