# SyncWatch同步观影 v2.3.8 发布说明

## 更新公告

- 修复共享播放的权威时间快照忽略当前倍速的问题。此前影片在高于 1 倍速播放时，服务端的周期同步会落后于实际进度，触发客户端回退定位，表现为重复播放和卡顿。
- 服务端现在以当前共享倍速累计播放时间；所有成员在任一成员调整倍速后都使用同一个进度基准继续播放。
- 新增回归测试：影片以 2.5 倍速运行后再次调整倍速时，验证服务端权威时间仍按 2.5 倍速推进，避免再次回退至已播放内容。

## 发布资产与验收边界

- 正式 Release 将包含 8 个维护者资产和 GitHub 自动生成的 2 个源码归档；Windows/Android 应用包必须由最终 `v2.3.8` Tag 对应源码真实重建。
- 发布前完成源码回归、Windows/Android 启动与核心流程、包内源码闭包、版本、平台/架构、非空大小、SHA-256 和 GitHub Release 下载回读核验。
