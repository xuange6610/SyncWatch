版本同步要求

每次版本变更都要更新 docs/wiki/ 中的版本公告和受影响教程，再把同名 Markdown 同步到 GitHub Wiki，并运行 node scripts/build-document-guides.js 更新主要 Pages HTML。完成后运行 npm run test:repo 与 git diff --check，逐页检查链接、版本号和“未验证”声明。只更新 README 或 Release 正文不算完成 Wiki 更新。

图文来源

Wiki 图片统一引用 docs/screenshots/ 中的已审核截图。新增截图前必须检查：不包含真实姓名、邮箱、访问令牌、私人 IP、房间链接或未授权媒体名称；截图应能证明一个真实功能，而不是只展示装饰界面。
