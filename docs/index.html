SyncWatch同步观影

把服务器、房间和媒体掌握在自己手里，让 Windows、Android、macOS 与浏览器中的成员同步看到同一刻。

局域网可直接连接，跨网络可按需启用 Cloudflare Tunnel 或自己的 HTTPS 反向代理。

从启动服务器到一起播放

不需要先理解全部技术名词。房主完成前三步，其他成员只需要一个地址。

  1. 1

    房主启动

    运行服务器 EXE，或在源码目录执行 npm start。

  2. 2

    完成安全设置

    登录默认管理员账号后立即改密码，再创建房间和房间密码。

  3. 3

    分享访问地址

    同一网络分享局域网地址；跨网络时启动临时公网访问或配置 HTTPS。

  4. 4

    成员加入

    成员用客户端或浏览器打开地址，进入房间后由房主统一开始播放。

一次操作，怎样变成所有人的同一画面

服务器保存权威房间状态。客户端提交播放意图，服务端完成认证、更新、持久化与广播；成员端再按服务器时间和网络延迟校正播放器。

阅读完整技术架构
调用链运行演示 Node.js · Express · Socket.IO · FFmpeg
  1. 01 启动核心 Electron、独立 Node 或 Android Service 启动 Express 与 Socket.IO server/index.js
  2. 02 客户端连接 浏览器、桌面端和 WebView 加载同源界面并建立实时连接 HTTP + WebSocket
  3. 03 认证与入房 校验密码哈希、会话、设备策略、协议、房间密码和权限 session / room
  4. 04 处理操作 更新播放状态；上传时使用 FFprobe 分析、FFmpeg 转换 state / media
  5. 05 安全写盘 配置原子替换，媒体与 secrets 分目录保存，单实例写入 SyncWatch同步观影-Data
  6. 06 广播结果 向房间发送版本化状态，客户端按时间与延迟修正画面 room-state / playback-sync
结果：所有成员收到同一份房间状态

播放、暂停、进度、倍速、聊天、通知和共享信令保持一致；媒体文件仍由房主自己的服务器提供。

拖动控制台旋转 360°，滚轮调整深度，方向键微调。动画只展示当前调用关系，不影响阅读。

用什么写的

网页使用原生 HTML、CSS、JavaScript；服务端使用 Node.js、Express、Socket.IO；桌面端使用 Electron；Android 使用 Java、C++ JNI、WebView 与 Node.js Mobile。

调用了什么

fetch 访问 REST API，Socket.IO 传递实时事件，WebRTC 协商语音和屏幕共享；FFprobe/FFmpeg 由服务端子进程调用，cloudflared 只在开启公网访问时运行。

数据怎样流动

文件和备份走 HTTP 流式传输，房间状态走 Socket.IO，媒体播放走 HTTP Range。账号、房间、媒体索引、记录和密钥分别写入本机数据目录。

运行在什么环境

源码服务器需要 Node.js 22+；Windows 完整 EXE 自带 Electron/Node/FFmpeg；Android 完整 APK 内置 Node.js Mobile；Docker 使用 Node.js 24 Linux 镜像。

数据目录到底保存什么

SyncWatch同步观影-Data/ 是这台服务器的运行数据，不是源码。迁移时应停止服务器并完整复制。

路径作用备份建议
config.json账号、房间、权限、设置和媒体索引必须备份，不要手工编辑
uploads/上传的影片、音频、字幕、图片和文档必须与索引一起备份
.secrets/、secrets/邮件密钥和管理员验证材料绝不能公开，随数据一起备份
compatible-media/自动生成的浏览器兼容媒体可以重建，空间不足时可在停机后清理
logs/、crash-dumps/运行和异常诊断信息提交 Issue 前先脱敏

只复制 config.json 会造成记录、文件或密钥不完整。软件内的“全部数据与配置”导出适合日常备份。

从源码启动：先打开终端，再逐条输入

Windows 在开始菜单搜索“PowerShell”或“终端”；macOS 打开“访达 → 应用程序 → 实用工具 → 终端”。普通使用者应优先下载已经构建的文件。

PowerShell / Terminal
cd $HOME\Desktop
git clone https://github.com/xuange6610/SyncWatch.git
cd SyncWatch
npm ci
npm start

每条命令执行后会发生什么

  1. cd $HOME\Desktop 把当前位置切到桌面，下载后的源码通常位于桌面 SyncWatch 文件夹。
  2. git clone 下载源码；npm ci 安装依赖，结束时应回到可继续输入命令的提示符。
  3. npm start 启动服务器；看到地址后打开 http://127.0.0.1:5000。
  4. 按 Ctrl+C 停止。下次只需进入该文件夹，再执行 npm start。
