SyncWatch同步观影

和朋友、家人一起看电影。每个人都能看到同一进度。

你自己保存账号和影片。电脑、手机、浏览器都可以加入。

前往下载 新手快速开始 GitHub主页

自己保存账号和影片放在你的设备上

电脑手机都能用Windows、Android、浏览器均可加入

一起互动播放、聊天、语音和共享都能用

先局域网再公网先在家里试用，需要时再分享给远方朋友

四步开始一起看

房主照着做，朋友拿到地址后就能加入。

  1. 1

    打开软件

    双击 Windows 完整版；开发者也可以运行 npm start。

  2. 2

    先改密码

    首次登录后马上设置新管理员密码，再创建房间。

  3. 3

    复制地址

    同一 Wi-Fi 直接分享局域网地址；远程使用时再开启公网访问。

  4. 4

    朋友加入

    朋友打开地址、登录并输入房间号，房主点击播放即可同步。

为什么大家能同步

服务器记住房间状态。有人播放、暂停或拖动时，服务器会告诉房间里的其他人。

阅读完整技术架构
调用链运行演示 Node.js · Express · Socket.IO · FFmpeg
  1. 01 打开服务器 软件启动一个供大家连接的房间服务 server/index.js
  2. 02 成员连接 浏览器、电脑和手机打开同一个地址 HTTP + WebSocket
  3. 03 登录入房 输入账号和房间密码，确认你有权进入 session / room
  4. 04 同步操作 播放、暂停、进度和倍速发送给所有成员 state / media
  5. 05 保存数据 账号、房间和影片信息保存在服务器数据目录 SyncWatch同步观影-Data
  6. 06 看到同一刻 每个人的播放器根据服务器时间自动校正 room-state / playback-sync
结果：大家看到同一进度

播放、暂停、进度、倍速和聊天会同步；影片仍保存在房主自己的服务器。

拖动控制台旋转 360°，滚轮调整深度，方向键微调。动画只展示当前调用关系，不影响阅读。

需要什么

普通用户下载 Windows 或 Android 文件即可。开发者从源码运行时需要 Node.js。

可以做什么

一起播放影片、聊天、发弹幕、语音通话，也可以共享浏览器标签页或窗口。

数据放在哪里

账号、房间、影片和聊天记录保存在你自己的服务器数据目录。

支持哪些设备

支持 Windows、Android 和现代浏览器。跨网络使用时可以配置 HTTPS 或临时公网地址。

数据会保存在哪里

SyncWatch同步观影-Data/ 保存账号、房间、影片和设置。换设备前先停止服务器并备份整个文件夹。

路径作用备份建议
config.json账号、房间、权限、设置和媒体索引必须备份，不要手工编辑
uploads/上传的影片、音频、字幕、图片和文档必须与索引一起备份
.secrets/、secrets/邮件密钥和管理员验证材料绝不能公开，随数据一起备份
compatible-media/自动生成的浏览器兼容媒体可以重建，空间不足时可在停机后清理
logs/、crash-dumps/运行和异常诊断信息提交 Issue 前先脱敏

只复制 config.json 会造成记录、文件或密钥不完整。软件内的“全部数据与配置”导出适合日常备份。

开发者如何启动

普通用户直接下载 Windows 完整版。开发者安装 Node.js 后，在项目文件夹打开终端运行命令。

PowerShell / Terminal
cd $HOME\Desktop
git clone https://github.com/xuange6610/SyncWatch.git
cd SyncWatch
npm ci
npm start

每条命令执行后会发生什么

  1. cd $HOME\Desktop 把当前位置切到桌面，下载后的源码通常位于桌面 SyncWatch 文件夹。
  2. git clone 下载源码；npm ci 安装依赖，结束时应回到可继续输入命令的提示符。
  3. npm start 启动服务器；看到地址后打开 http://127.0.0.1:20311。
  4. 按 Ctrl+C 停止。下次只需进入该文件夹，再执行 npm start。

下载哪个文件

想自己开房就下载 Windows 完整版；只想加入别人的房间就下载体验版或 Android APK。

直接下载 Windows 完整便携版 阅读完整使用说明
  • 客户端Experience 体验版Windows 成员客户端，只连接已有服务器。
  • 服务器Windows 完整便携版下载后直接双击，适合自己开房。
  • 客户端Android APK通用 ABI，加入房间或在受支持设备运行手机服务器。
  • 服务器环境源码与独立服务端源码 ZIP · 源码 TAR.GZ；需要 Node.js，适合开发、审查或长期部署。
  • 服务器工具Node.js / cloudflared需要自己搭建服务器时再下载这些工具，文件都在 v2.4.3 下载页。
  • 小提示第一次登录后先改管理员密码；遇到问题先在局域网测试。
