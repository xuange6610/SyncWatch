cloudflared：从安装到临时地址

  1. 先启动 SyncWatch 并确认 http://127.0.0.1:20311 可打开。
  2. Windows 下载 cloudflared 后运行 .\\cloudflared.exe --version。
  3. 运行 .\\cloudflared.exe tunnel --url http://127.0.0.1:20311 --protocol http2。
  4. 复制 trycloudflare.com 地址；按 Ctrl+C 停止。

临时地址接口超时

新版最后一次自动尝试会恢复系统网络/代理并取消物理网卡绑定。仍失败时允许 TCP 443、TCP/UDP 7844，在 VPN/TUN 中将 cloudflared 和 Cloudflare 域名设为直连，或取消“绕过系统代理”后运行网络诊断与修复。

Node.js：Windows

  1. 普通 Intel/AMD 电脑安装 node-v24.19.0-x64.msi；Windows on ARM 使用 arm64 MSI。
  2. 重新打开终端，运行 node --version 和 npm --version。
  3. 源码目录执行 npm ci 和 npm start。
