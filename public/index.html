    SMTP 设置
    配置验证码邮件的发件服务器。QQ 邮箱可填写 smtp.qq.com、465，并使用邮箱授权码。
    
                
    SMTP 配置步骤
    1. 在邮箱网页设置中开启 SMTP 服务并生成“授权码”，不要填写邮箱登录密码。
    2. QQ 邮箱填写 smtp.qq.com、端口 465、勾选隐式 TLS；网易邮箱可填写 smtp.163.com、端口 465。
    3. SMTP 用户名和发件人邮箱填写完整邮箱地址，授权码填入“SMTP 密码 / 授权码”。
    4. 先保存设置，再依次点击“测试连接”和“发送测试邮件”。
    5. 连接失败时检查邮箱服务是否开启、授权码是否过期、防火墙是否允许 465/587 端口。
    示例：主机 smtp.qq.com · 端口 465 · 用户名 movie@qq.com · 隐式 TLS 开启。

    公网访问教程
    让外网设备加入当前服务器
    一、临时公网地址（推荐首次使用）
    1. 在“公网访问”中选择“临时公网地址”。
    2. 无需填写令牌或域名，直接点击“开启公网访问”。
    3. 等待状态显示“已开启”并出现绿色可用地址。
    4. 点击“分享公网地址”或“分享房间”，系统会自动附带当前房间号。
    分享示例https://example.trycloudflare.com/?room=ADMIN
    临时地址每次重新开启可能变化，适合临时观影和快速测试。运行期间即使延迟探测暂时超时，程序也会保持当前地址，不会主动重启隧道。
    二、稳定隧道（固定域名）
    1. 先在 Cloudflare Zero Trust 创建 Tunnel，并把域名指向该 Tunnel。
    2. 复制 Tunnel Token，在软件中选择“稳定隧道”。
    3. “Cloudflare Tunnel 令牌”填写完整令牌；“已绑定地址”填写站点根地址。
    4. 点击“开启公网访问”，验证成功后即可使用固定域名。
    填写示例令牌：eyJhIjoi...完整令牌...公网地址：https://watch.example.com
    公网地址只填写根地址，不要填写房间号、路径、查询参数、用户名或密码。
    三、房间与播放检查
    • 建议为公开房间设置访问密码，再把带房间号的地址发送给成员。
    • 公网状态会显示延迟；探测波动会保持当前地址，只有 cloudflared 进程真正退出才会显示运行异常。
    • 公网网页客户端默认使用原画；网络受限时可在播放器中手动切换流畅版或自动模式，已保存的清晰度选择仍会保留。
    • 视频需要支持 HTTP Range。服务器本地影片会自动提供 Range，COS/OSS 直链也必须允许跨域和 Range。
    • 连接不上时，先点击“关闭”强制停止，再重新开启；同时检查系统代理、防火墙和 Cloudflare 域名配置。
    
  
    房间与上传
    上传限制怎么设置
    文件大小
    单位是兆字节（MB）。填写 1024 表示单个文件最大 1 GB；填写 10240 表示最大 10 GB；填写 0 表示不限制单个文件大小。
    上传时长
    单位是秒。填写 3600 表示单次上传最长 1 小时；填写 0 表示不限制上传时间。慢速公网或大体积 4K 影片建议保留更长时间。
    推荐设置
    局域网可设置为 0 / 0。公网服务器建议按磁盘容量限制文件大小，并把时长设置为 7200 秒以上。修改后只影响新开始的上传任务，不会删除已有影片。
    上传失败时
    客户端会对网络中断自动重试，不完整的临时文件不会进入影片库。m3u8 清单必须与分片资源一起可访问；只有清单文件时，其他设备可能无法播放其中引用的分片。
